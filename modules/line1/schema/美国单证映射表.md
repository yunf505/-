# 美国单证 → 契约A 字段映射表（v1.0 · 2026-10-07）

回应线2 B 的阻塞项 #2（7501→契约A 无映射表）与 #3（CBP 代码无法判等价）。
适用：`commercial_invoice` / `packing_list` 之外的**美国侧单证**（CBP Form 7501、3461）映射到契约A
`customs_declaration`；并给出**跨证同一实体比对矩阵**。
栏号依据：`赛题二测试资料/02-官方空白与版式样张/CBP表单族/B-套1-CBP-7501进口报关单.pdf`
（OMB 1651-0022，有效期至 2026-02-28）的表体与填表说明原文。

## ⚠ 0. 先记一条：栏号会随表单改版漂移

| | 2009 年版（套B p49 实测） | 现行版（官方空白表单） |
|---|---|---|
| Ultimate Consignee | 栏 **25** | 栏 **29** |
| Importer of Record | 栏 **26** | 栏 **30** |
| HTSUS No. | 栏 32 行项内 | 栏 **33. A.** |
| 现行版栏 25 / 26 是什么 | — | **Location of Goods/G.O. No.** / **Consignee Number**（含义完全不同！） |

**规则：抽取与比对一律以"栏位名称"为准，禁止以编号为准。** 抽取时 `raw_span` 必须带栏位名称原文
（如 `"30. Importer of Record: …"`），不要只写 `"栏30"`。

## 1. CBP Form 7501（Entry Summary）→ 契约A `customs_declaration`

| 7501 栏（现行） | 栏名 | 契约A 字段 | 归一化/注意 |
|---|---|---|---|
| 1 | Filer Code/Entry Number | `declaration_no` | 报关单号取 **Entry Number 段**；美国件为 `DDD-XNNNNNN-X` 形态，与中方 18 位规则无关，`normalized=false` 保留原串 |
| 2 | Entry Type | —（写 warnings） | 01 正式 / 06 FTZ / 21 等，契约A 无承载字段 |
| 3 | Summary Date | —（见 §4 日期链） | 汇总日 |
| 6 | Port Code | `port_of_destination` 旁证 | 4 位 `DDPP`；见 §5 |
| 7 | Entry Date | `declaration_date` | **申报日取栏7，不取栏3**（见规程 §5.9） |
| 9 | Mode of Transport | `transport_mode` | 枚举映射见 §5.2；**未查官方码表前 confidence≤0.5** |
| 10 | Country of Origin | `trading_country` | 语义近似但非等同，见 §3 注 |
| 11 | Import Date | —（见 §4 日期链） | |
| 12 | B/L or AWB Number | —（跨证主键，写 warnings 或扩展字段） | **提单号**，与 `bill_of_lading.bl_no` 比对 |
| 13 | Manufacturer ID | —（卖方弱线索） | 不作硬比对 |
| 14 | Exporting Country | `trading_country`（优先用此栏） | 贸易国取 **14**，10 是货物原产国 |
| 15 | Export Date | —（见 §4 日期链） | |
| 18 | Missing Docs | —（**"单证缺失"官方显式栏**） | 非空即代表 CBP 已登记缺件，比对时优先采信 |
| 19 | Foreign Port of Lading | `port_of_dispatch` | 5 位外国港码，见 §5 |
| 20 | U.S. Port of Unlading | `port_of_destination` | 4 位美国港码 |
| 29 | Ultimate Consignee | `overseas_consignee` **不要用**，见 §3 | |
| 30 | Importer of Record | `domestic_consignor` | 美国境内登记进口人 |
| 32 | Description of Merchandise | `goods_name` | |
| 33.A | HTSUS No. | `hs_code`（数组，逐行全收） | 去点补足 10 位；**99 章附加税目（如 9903.88.09、9903.85.01）不进数组**，写 warnings |

## 2. CBP Form 3461（Entry/Immediate Delivery）→ 同一 `customs_declaration` 记录

3461 是**同一票的另一份单证**，不单独成记录；其字段用于交叉印证：
栏4 Entry Number→`declaration_no`；栏21 IT/BL/AWB→提单号；栏22 Manifest Quantity→`packages`；
栏23 HTS Number→`hs_code`；栏19 Total Value→`total_value`；栏10 Ultimate Consignee / 栏11 Importer of Record→`domestic_consignor`。

## 3. 跨证"同一实体"比对矩阵（B 最需要的部分）

| 业务实体 | 7501 取哪个栏 | 发票 | 装箱单 | 提单 | 契约A 比对键 |
|---|---|---|---|---|---|
| **买方 / 美国进口方** | 栏30 Importer of Record（栏29 Ultimate Consignee 作旁证） | `buyer` | `buyer` | `consignee` | `customs_declaration.domestic_consignor` ↔ `commercial_invoice.buyer` ↔ `packing_list.buyer` ↔ `bill_of_lading.consignee` |
| **卖方 / 发货方** | ⚠ 无对应栏（栏13 Manufacturer ID 仅弱线索） | `seller` | `seller` | `shipper` | `commercial_invoice.seller` ↔ `packing_list.seller` ↔ `bill_of_lading.shipper`（**不与 7501 比**） |
| **箱号（最强键）** | 无 | `container_no` | `container_no` | ⚠ **提单侧无此字段**，见下方"遗留缺口" | 三方 `container_no` |
| 提单号 | 栏12 B/L or AWB Number | — | — | `bl_no` | `bill_of_lading.bl_no` ↔ 7501 栏12（需扩展字段，暂走 warnings） |
| 件数 | 栏34.B Manifest Qty | `packages` | `packages` | `packages_and_weight.packages` | 同名四对齐 |
| 毛重 | 栏34.A（分行，需加总） | `gross_weight_kg` | `gross_weight_kg` | `packages_and_weight.gross_weight_kg` | 同上 |
| 金额 | 栏39 Total Entered Value | `total_value` | — | — | 见 §6 容差 |

**关键澄清（回答 B 的提问"拿哪个字段对发票 To"）**：对 **`domestic_consignor`**。
`overseas_consignee` 在美国件上**一律置 null**——契约A 该字段是"中国进口报关单视角的境外收货人"，
美国 7501 的栏29/30 都是**美国境内主体**，语义无对应物，拿它去比发票 To 会产生假一致。

**遗留缺口（需全队确认，见 docs/定稿确认单.md）**：`bill_of_lading` 的 field_specs 里
**没有 `container_no` / `marks`**，而箱号是最强跨证键。当前只能从提单 `goods_description` 的
`raw_span` 里正则捞（如 `SEGU9170820 / VN149125A`）。建议 v0.5 给 `bill_of_lading` **追加**这两个
可选字段（属"只加不改"），待确认后落地。

## 4. 日期链判据（供 B 实现"日期逻辑矛盾"检测）

```
栏15 Export Date  ≤  提单 ON BOARD Date  ≤  栏11 Import Date  ≤  栏7 Entry Date  ≤  栏3 Summary Date
发票 invoice_date ≤ 栏15 Export Date + 合理窗口（合同/信用证约定）
```
违反上序即"日期逻辑矛盾"。注意套B 实测：发票日 2009-07-11 = 提单 ON BOARD 2009-07-11 = 栏15 Export Date
2009-07-11，三者同日属正常，**不要误报**。

## 5. CBP 代码处理规则

### 5.1 港口码
- 官方出处（7501 填表说明原文）：**Block 6 记录 U.S. port code，取自 HTS《Schedule D, Customs District
  and Port Codes》，即 HTS Annex C**；Block 20 明确"**Do not show the name of the port instead of the
  numeric code**"。美国港码 4 位 `DDPP`，外国港码（栏19）5 位。
- 本轮**未能取到 Annex C 电子件**（USITC reststop 对该文件名返回 503），下表为**同票配对反推**
  （7501 存代码 + 同票提单存地名），每条 n=1，**仅供实现参考，须以 Annex C 核验后方可作硬判据**：

| 代码 | 反推地名 | 证据（同票配对） |
|---|---|---|
| 2704 | US Los Angeles, CA | 套B：7501 栏6/20=2704 ↔ 提单 p76 POD "LOS ANGELES, CA"；另见 04-Alcharihi、11-Sanho |
| 57078 | CN Yantian | 套B：7501 栏19=5707**B**（8/B 形近混淆）↔ 提单 p76 POL "YANTIAN" |
| 5301 | US Houston, TX | 套A：7501 栏6=5301 且 栏20 U.S. Port of Unlading=5301 ↔ 同票提单 p150 交货港 "HOUSTON"（栏6 与栏20 同为 5301，自洽）；另 07-LFRCarli 亦 5301 |
| 5203 | US Miami, FL | 套C：7501 栏6/20=5203 ↔ 收货地 OPA LOCKA FL |
| 24741 | DO Rio Haina | 套C：栏19=24741 ↔ 提单 POL "RIO HAINA DR" |
| 2720 / 4601 / 1601 | 未定 | 01/02 为空运（Mode 40），4601/1601 无同票提单可反推 |

  > 反推法只到"够实现比对规则"为止：**证据不足或仅 n=1 的代码，一律按 §5.1 规则判"不可比"，不要猜地名。**
- **比对规则（B 可直接实现）**：
  1. 两侧都是代码 → 比**代码串全等**（去空格）；
  2. 一侧代码一侧地名 → 判"**不可比**"（黄色），**不得判不一致**；
  3. 两侧都是地名 → 地名归一化（大写、去标点、`LOS ANGELES`≡`LA`）后比全等；
  4. 抽取侧维持现状：代码原样存、`normalized=false`。

### 5.2 运输方式 Mode of Transport
- 同票反推证据：**11 一律配船名**（CMA CGM GEMINI / OOCL BERLIN / MSC AMALFI / Ocean B/L）→ `sea`；
  **40 配航空公司**（CZ/CA）+ 11 位 AWB → `air`；**10** 出现在 11-Sanho（承运 EGLV-SEAMAX NEW H，Ocean B/L）→ 亦属水运族。
- 规则：`1x → sea`、`4x → air` 可先落地（confidence 0.7，`normalized=true`）；
  但 **10 与 11 的精确区分（如集装箱船/散货）须查 CBP 官方码表**，未查得前在 warnings 注明"按码族映射"。
- 契约A 枚举：`sea|air|rail|road|multimodal`。

## 6. 金额比对容差（回应 B 的 0.40 USD 案例）
套B：发票 `US$26,762.40` vs 7501 栏39 `$26,762.00`，差 **0.40（0.0015%）**。
建议判据：`|a-b| ≤ max(1.00, 0.5% × max(|a|,|b|))` → 记"容差内差异（绿/提示）"，**不标红**；
超过则标红。理由：7501 的 Entered Value 允许取整申报，逐分相等反而不真实。
